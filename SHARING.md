# Queue Ping community sharing kit

Queue Ping grows best through useful, honest recommendations—not spam. Follow each community's self-promotion rules, disclose that this is your project, and answer technical or safety questions directly.

## Suggested post title

```text
I made a free Windows tool that sends a phone notification when Dota 2 finds a match
```

## Suggested short post

```text
Long Dota queues kept tying me to the PC, so I built Queue Ping: a free, open-source PowerShell notifier for Windows 10/11.

It uses Dota's built-in “Bring Dota 2 to front when match found” behavior, confirms the foreground transition, sends one urgent ntfy phone notification, and exits. It does not read game memory, inject code, inspect traffic, modify game files, send input, or accept the match.

Dota mode has been tested with a real match. League Ready Check support is included as an experimental foreground-only mode.

Source, download, privacy notes, and setup guide:
https://archaniaaa.github.io/dota2-league-phone-notifier/
```

## Suggested one-line description

```text
Queue Ping is a free, open-source Windows notifier that sends your phone an ntfy alert when Dota 2 finds a match—without reading memory or accepting for you.
```

## Good places to share

- Communities where Dota 2 players discuss long queues or match-found notifications.
- Windows and PowerShell communities interested in small open-source utilities.
- ntfy communities interested in practical notification integrations.
- Friends' Discord servers when their rules allow personal project sharing.

Do not repeatedly repost, mass-message people, buy engagement, or promise that League support works on every PC. Invite users to test the harmless foreground simulation before a real queue.
