HOW IT WORKS

One Windows signal. One urgent push. Nothing more.

Queue Ping observes the foreground application that Windows already exposes. It never looks inside the game.

  1. 01

    Start your queue

    Enable Dota 2's built-in “Bring Dota 2 to front when match found” option, then begin matchmaking.

  2. 02

    Arm Queue Ping

    Alt+Tab away, press Enter in the notifier, and leave it waiting with negligible CPU use.

  3. 03

    Get the phone alert

    When Dota becomes foreground and stays there briefly, Queue Ping sends one ntfy notification and exits.

COMMON QUESTIONS

Dota 2 phone notification FAQ

How do I get a phone notification when Dota 2 finds a match?

Enable Dota 2's foreground-on-match-found option, start Queue Ping, subscribe to its private ntfy topic, and arm it after matchmaking begins. It alerts your phone when Dota becomes foreground.

Does Queue Ping automatically accept a Dota 2 match?

No. It only observes the foreground-window transition and sends a push notification. You must return to the PC and accept manually.

Is it free, and does it need an account?

The project is free and open source. Queue Ping has no account system, payment features, advertising, analytics, or telemetry. The public ntfy service can be used without creating a Queue Ping account.

Does it read Dota 2 or League of Legends memory?

No. It does not read memory, inject code, inspect network traffic, modify game files, or send game input. It only checks which process owns the Windows foreground window.

Why is League of Legends support experimental?

League does not guarantee that Ready Check will take foreground. If it only flashes on the taskbar, a foreground-only notifier cannot detect that queue event.

Will it work while the PC is asleep?

No. Windows, the game client, the notifier, and the internet connection must remain active while you queue.
